## 🌍 Overview | نظرة عامة
**CodeKody** is the premier interactive e-learning platform designed specifically for the Arab world to learn programming and software development. Starting from absolute scratch, the platform guides students step-by-step to become professional developers ready for the global market. 

**CodeKody** هي المنصة التفاعلية الأولى في العالم العربي المصممة خصيصاً لتعليم البرمجة وتطوير البرمجيات. تبدأ المنصة مع الطلاب من الصفر تماماً وترافقهم خطوة بخطوة حتى الاحتراف والجاهزية التامة لسوق العمل.

---

## ✨ Key Features | المميزات الرئيسية

*   **Interactive Learning (تعلم تفاعلي):** Specially designed tracks and interactive assignments to simplify complex coding concepts.
*   **Professional Mentorship (توجيه ودعم مستمر):** Direct 1-on-1 support and guidelines from senior engineers to resolve blockages and errors.
*   **Applied Projects (مشاريع تطبيقية):** Real-world projects simulating industry requirements to build outstanding portfolios.
*   **Certified Path (شهادات معتمدة):** Certified credentials upon completion of study paths to validate skills and boost job applications.
*   **Dev Community (مجتمع مبرمجين):** A vibrant developer community to network, share knowledge, and collaborate.
*   **Career Guidance (إرشاد مهني):** Job preparation consulting, CV/Resume building, and LinkedIn optimization.

## 💼 Subscription Plans | الباقات المتاحة

### 1. Smart Coding Path (باقة التأسيس والتطبيق الذكي)
*Ideal for solid core programming foundation and portfolio building.*
*   Recorded high-quality courses available 24/7.
*   Interactive tasks and programming challenges (Tasks) after each session.
*   Technical support to solve coding issues and errors.
*   Access to the CodeKody Student Community.
*   Certificate of completion.

### 2. Pro Mentor Path (باقة الاحتراف والتوجيه الشخصي - السوبر)
*Elite plan featuring personal 1-on-1 guidance and comprehensive job market preparation.*
*   Includes **all features** of the Smart Coding Path.
*   1-on-1 follow-ups with a professional Software Engineer.
*   Personalized evaluations to track strengths and weaknesses.
*   Individual **Code Review** sessions to ensure industry-grade clean code.
*   Career consulting (mock interviews, resume prep, LinkedIn guidance).
*   Priority support and instant response.

## 🛠️ Technology Stack | التقنيات المستخدمة

-   **Framework:** [Next.js 16](https://nextjs.org/) (utilizing Turbopack & React 19)
-   **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with PostCSS
-   **UI & Icons:** Radix UI, Lucide React, and Tabler Icons
-   **Language:** TypeScript
-   **Performance:** Vercel Speed Insights integration
-   **Theme & RTL:** Custom Light/Dark theme switcher with full Right-To-Left (RTL) Arabic Cairo font rendering

## 🚀 Getting Started | البدء بالعمل

### Prerequisites
Make sure you have Node.js and `yarn` (or `npm`) installed.

### Installation
Clone the repository and install the dependencies:
```bash
yarn install
# or
npm install
```

### Run Local Development Server
Launch the development server with Turbopack:
```bash
yarn dev
# or
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

### Build for Production
Create an optimized production bundle:
```bash
yarn build
# or
npm run build
```
